# Дипломный проект Django: Интернет-магазин

Проект представляет собой бэкенд-приложение на Django REST Framework, интегрированное с готовым фронтендом.

## Технологический стек
- Python 3.12
- Django 5.x
- Django REST Framework
- Celery / Redis (для отложенных задач)
- Node.js & npm (для сборки фронтенда)
- SQLite3 / PostgreSQL

## Как запустить проект локально

1. **Клонировать репозиторий и перейти в папку:**
   ```bash
   git clone -b Basalyga_market <https://skillbox.ru>
   cd PythonProject_fin
   ```

2. **Cоздать и активировать виртуальное окружение:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Linux/macOS
   # .venv\Scripts\activate   # Для Windows
   ```

3. **Установить зависимости бэкенда:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Установить зависимости фронтенда:**
   > **Обратите внимание:** Зависимости фронтенда не устанавливаются автоматически. Перед открытием сайта в браузере их необходимо развернуть вручную из папки со статикой или корня проекта (где лежит `package.json`):
   ```bash
   npm install
   ```

5. **Создать файл конфигурации `.env` в корне проекта и заполнить его по образцу:**
   * Скопируйте структуру из файла `.env.example` или создайте файл `.env` вручную.
   * Укажите следующие обязательные переменные:
     - `DEBUG` — режим отладки (поставьте `True` для разработки).
     - `SECRET_KEY` — секретный ключ вашего Django-проекта.
     - `CELERY_BROKER_URL` — URL-адрес брокера очередей Redis (например, `redis://127.0.0.1:6379/0`).
     - `CELERY_RESULT_BACKEND` — URL-адрес хранилища результатов Redis (например, `redis://127.0.0.1:6379/0`).

   **Пример готового файла `.env`:**
   ```env
   DEBUG=True
   SECRET_KEY=django-insecure-qe_sj\$fj1a##ajz8_!f7a#me#wu)f22)t*40&v@4diz@ret-o8
   CELERY_BROKER_URL=redis://127.0.0.1:6379/0
   CELERY_RESULT_BACKEND=redis://127.0.0.1:6379/0
   ```

6. **Выполнить миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

7. **Загрузить демонстрационные данные (Фикстуры):**
   > **Важно для проверки:** Чтобы база данных куратора не оставалась пустой и на сайте сразу отображались книги, категории, обложки и теги, перед запуском обязательно выполните команду:
   ```bash
   python manage.py loaddata complete_fixtures.json
   ```

8. **Запустить локальный сервер бэкенда:**
   ```bash
   python manage.py runserver
   ```

9. **Запустить локальный сервер фронтенда:**
   ```bash
   npm run dev
   ```
